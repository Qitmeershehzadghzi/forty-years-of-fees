# Admin panel

npm install
npm run dev

Open http://localhost:5174/admin/. Backend runs on port 5000. The public frontend runs on port 5173. Production: npm run build in both admin and frontend; backend serves /admin separately. Authentication and database access stay in backend.

## Researcher workflow
Sign in with the designated administrator. Choose entry year and programme, then amount, fee unit, component, campus and term. Add the exact source URL/title/page. Check verification only after checking the original document; unchecked entries stay private drafts. Save updates the graph. Use Graphs & findings to select matching unit, term, CPI series and reference year. Public archive shows published fees with verified sources. Current imported records use calendar year 2026, Fall term, per-course tuition; 2017 archive uses per-credit tuition. Five 2020 draft records await original source verification. Research desk provides full structured editing of imported fees, programmes, sources and CPI.
